# 面接対策出力デザイン仕様

## 2. 各タブの出力構成

### 2-1. 想定問答集（qa）

```
# 想定問答集

**方針**: 結論ファースト（PREP）＋具体例（STAR）、1回答30〜90秒、語尾は丁寧体

> 凡例：**Q** = 面接官の質問 ／ **A** = 想定回答（口語ベース） ／ 💡 = 答え方のコツ

---

## A. 導入・定番質問

### Q1. [質問文]
**A**（約60秒）
「[口語体の回答]」

💡 **[コツのタイトル]**: [ポイント・狙い]

---

## B. 志望動機（最重要）
...
## F. リスク質問
...（カテゴリA〜H、最低30問）
```

カテゴリ一覧:
- `A: 導入・定番` / `B: 志望動機` / `C: 職務経歴掘り下げ`
- `D: 業務理解・職種特化` / `E: 組織適性・価値観` / `F: リスク質問`
- `G: 人物・価値観` / `H: 締め`

## 3. フロントエンド表示ルール（step4/page.tsx）

- **Markdown レンダリング**: `react-markdown` + `remark-gfm` を使用
- **カスタムレンダラー** で以下を適用:
  - `blockquote` → 青左ボーダー + `#eff6ff` 背景
  - `💡` で始まる段落 → `#fef3c7` 背景 + amber 左ボーダーのヒントボックス
  - `🚫` で始まる見出し/段落 → `#fef2f2` 背景 + red 左ボーダー
  - `✅` で始まる見出し/段落 → `#ecfdf5` 背景 + green 左ボーダー
  - `table` → ヘッダー `#1e40af`、偶数行 `#f1f5f9`
  - チェックボックスリスト（`- [ ]`） → インタラクティブ checkbox
  - `★★★` / `★★☆` / `★☆☆` → バッジ表示
  - `## A.` 〜 `## H.` のカテゴリ見出し → カテゴリバッジ付きで表示
- **ストリーミング中**: 最後の行末にカーソルアニメーション
- **完了後**: キーワード検索・お気に入り機能

## 4. PDF生成ルール（main.py _markdown_to_pdf_bytes）

- **ページヘッダー**: `#0b1e4d → #3b82f6` グラデーション風の帯（ネイビー背景 + 白文字）
- **H1**: `#0b1e4d`、下線 `#3b82f6`
- **H2**: `#1e40af`
- **H3**: `#1e3a8a`
- **💡 段落**: `#fef3c7` 背景ボックス、左ボーダー `#f59e0b`（ReportLab `Table` で実装）
- **🚫 段落**: `#fef2f2` 背景ボックス、左ボーダー `#ef4444`
- **テーブル**: ヘッダー行 `#1e40af` 背景・白文字、偶数行 `#f1f5f9`
- **チェックボックス** (`- [ ]`): ☐ 記号に変換
- **チェック済み** (`- [x]`): ☑ 記号に変換
- **`---` セパレーター**: `#93c5fd` の破線 HR
- **フォント**: HeiseiKakuGo-W5（Bold）/ NotoSansJP（通常）
